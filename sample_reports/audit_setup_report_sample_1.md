# Architecture Decision Points

- **Decision:** Skills and commands live only in `.claude/` (local contributor use), not at plugin root
  - **Apparent intent:** Contributors can use the skill while working on this repo without a `--plugin-dir` flag
  - **Cost:** The plugin root has no `skills/` or `commands/` directories — nothing to distribute as a plugin
  - **Alternative:** Move canonical files to `skills/` and `commands/` at root; keep `.claude/` as either symlinks or a contributor-convenience copy; or use `--plugin-dir .` for local dev
  - **Verify with developer:** yes — this is the core structural decision to resolve before publishing

- **Decision:** Single monolithic `SKILL.md` containing the full audit specification (~1,075 lines)

# Recommended Claude Code Architecture

- `CLAUDE.md` (project root) — contributor orientation: folder layout, dev workflow, naming rules, what not to commit
- `skills/audit-setup/SKILL.md` — the full audit specification (plugin artifact)
- `.claude/skills/audit-setup/SKILL.md` — contributor mirror OR removed in favour of `--plugin-dir .`
- `.claude/commands/audit-setup.md` — thin dispatcher to skill (correct as-is)

**Slash command responsibilities:**
- Thin dispatcher only — pass `$ARGUMENTS` to skill, nothing else

**Skill responsibilities:**
- Full audit logic in `SKILL.md` — single-agent, no subagents, no orchestration scripts needed at this scale

**Subagent responsibilities:**
- None currently — appropriate. Future: if individual audit sections become expensive, section-specific subagents could run in parallel

**Script responsibilities:**
- None currently needed. Future: `scripts/sync-skills` to copy `skills/` → `.claude/skills/`

**Runtime artifact handling:**
- `.claude/audits/` must be gitignored — reports may contain sensitive project context
- `sandbox/` must be gitignored

**Model routing:**
- No override set — inherits session model (appropriate; this skill benefits from a capable model)

**Compact vs deep mode:**
- Currently single mode only — acceptable for now
